# Многопоточная симуляция движения поездов (C++)

## Описание проекта

Данная программа представляет собой учебную симуляцию движения поездов по железнодорожной ветке Таджикистана на примере маршрута **Душанбе – Куляб**.  
Основная цель работы — продемонстрировать использование **многопоточности**, **синхронизации потоков** и **работы с временем** в языке C++.

Каждый поезд моделируется как отдельный поток выполнения, а станции выступают в роли ограниченных ресурсов, на которые может одновременно прибывать только один поезд.

---

## Основные возможности программы

- Каждый поезд работает в отдельном потоке (`std::thread`)
- Минимальное количество поездов — **8**
- Поезда стартуют с разных станций маршрута
- На одной станции одновременно может находиться **только один поезд**
- Все события (ожидание, прибытие, отправление, завершение маршрута) логируются в консоль
- В логах отображается **реальное текущее время с миллисекундами**
- Перемещение между станциями и стоянки не являются мгновенными
- Корректная поддержка **кириллицы в консоли Windows**
